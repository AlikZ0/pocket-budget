# Проверка качества / Quality report — Pocket Budget 1.3.0

## Проверено в этой среде

- Автономные проверки алгоритмов: `node scripts/test-core.mjs` — 11 успешных сценариев.
- `tsc --noEmit --strict ...` для независимых расчётных модулей и таблицы локализаций — успешно.
- Синтаксический разбор исходных `.ts` / `.tsx` — без ошибок.
- Разбор CSS через `tinycss2` — без синтаксических ошибок.
- ZIP-архив исходников создаётся и проверяется на целостность записей.

## Добавлены тесты для запуска при доступных npm-зависимостях

- `tests/quality.test.ts`: запрет изменения серии с уже выполненным будущим платежом; отмена разового платежа с сохранением истории; даты и остаток долга после каждого погашения; проверка категорий при разделении серии.
- `tests/browser/quality.spec.ts`: восстановление ZIP сразу на первом экране, исправление начального остатка, клавиатурная навигация по прогнозу.
- Существующие: `tests/recurrence.test.ts`, `tests/backup.test.ts`, `tests/debts.test.ts` и адаптивные браузерные тесты для 320 / 390 / 768 / 1280 px.

## Что здесь не подтверждено

В среде выполнения npm-реестр недоступен, а пакеты Vite, React, Dexie и Playwright не установлены. Поэтому `npm install`, полная сборка `npm run build`, `npm test` и `npm run test:e2e` **не были успешно завершены**. Нельзя утверждать, что проверена работа на реальном iPhone или в Chromium.

После установки зависимостей запустите:

```bash
npm run check
npm test
npm run build
npm run test:e2e
```

Тесты Playwright используют локальный dev-сервер; браузер Chromium потребуется установить командой `npx playwright install chromium`.

## Поведение данных при обновлении

- Схема IndexedDB не обнуляется: используется ранее существующее имя `pocket-budget-v1` и миграции v1–v3.
- ZIP-формат остаётся v2 (архивы v1 поддерживаются); версия приложения повышена до 1.3.0.
- Сам факт обновления исходников не переносит данные между доменами: браузер привязывает IndexedDB к origin. Сохраните прежний origin или импортируйте ZIP-копию.
- При открытии PWA по `http://192.168.x.x` запись через IndexedDB обычно работает, но service worker недоступен без HTTPS. Для офлайн-установки используйте HTTPS.
- Данные и ZIP не зашифрованы. На чужом телефоне или общем браузерном профиле их конфиденциальность не гарантирована.
