# Компактный армянский интерфейс — 1.4.1

Изменены только UI-подписи и стили, пользовательские данные не меняются.

| Контекст | Полная подпись | Короткая версия |
|---|---|---|
| Нижняя навигация | Ամփոփում | Գլխավոր |
| Нижняя навигация | Գործարքներ | Գործարք |
| Нижняя навигация | Կարգավորումներ | Կարգ․ |
| План, фильтр статуса | Պլանավորված | Պլանում |
| Долги, история | Մարումների պատմություն | Պատմություն |

Короткие версии применяются к тесным кнопкам. В `aria-label` остаются полные названия. Другие длинные кнопки и подписи (например, экспорт данных и прогноз) получили более лаконичные варианты в армянском переводе. Предупреждения и юридически значимые подтверждения сохранены развернутыми.

## Проверка

- Статическая проверка CSS в Chromium: 320, 390, 768, 1280 px, нет обрезания компактных подписей и горизонтальной прокрутки.
- `tests/browser/armenian-compact.spec.ts` дополнительно проверяет это на реальном приложении при запуске Playwright.
- `tests/i18n-compact.test.ts` проверяет компактные переводы, полные подписи и другие языки.
- `node scripts/test-core.mjs`: 11 проверок расчётов прошли.
- npm install / полноценная сборка Vite / тесты Playwright в данной среде не выполнены (сетевые зависимости недоступны). Требуется локальный запуск.

Для проверки на Ubuntu: `npm install && npm run check && npm test && npm run build && npm run test:e2e`.
